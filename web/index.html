04 / THE IDEA

A Bitcoin miner
with a better job.

I originally had an ESP32 display showing mining statistics. I wanted to make something more useful for my everyday work with networking, Linux and infrastructure.

The result is a small, standalone utility rather than a replacement for a terminal. It does not need a PC companion, API key or account to run. Wi-Fi/BLE radios stay disabled until you choose to scan. The clock has no NTP or battery-backed RTC, so its time must be set manually after power loss.
